# metathis: HTML Metadata Tags for 'R Markdown' and 'Shiny'

Create meta tags for 'R Markdown' HTML documents and 'Shiny' apps for
customized social media cards, for accessibility, and quality search
engine indexing. 'metathis' currently supports HTML documents created
with 'rmarkdown', 'shiny', 'xaringan', 'pagedown', 'bookdown', and
'flexdashboard'.
